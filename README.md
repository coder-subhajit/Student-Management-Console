# Student Management Console

A simple console-based Student Management System built using **Java, JDBC, Maven, and MySQL**.

## 🚀 Features
- Add new students
- View student records
- Update student details
- Delete student records

## 🛠️ Technologies
- Java
- JDBC
- MySQL
- Maven
- IntelliJ IDEA

## ⚙️ Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/coder-subhajit/Student-Management-Console.git
   ```
2. Open the project in IntelliJ IDEA.
3. Create a MySQL database.
4. Configure database credentials.
5. Reload Maven dependencies and run the main class.
